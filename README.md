## 📚 Course Modules & Syllabus

### 🔹 Module 1: Web Fundamentals
* **HTML5:** Semantic structure, text elements, media, forms, accessibility, and SEO basics.
* **CSS3:** Styling, Flexbox, CSS Grid, responsiveness, animations, and clean UI principles.
* **Bootstrap 5:** Utility classes, responsive grid system, ready-made components, and theme customizations.
* **Version Control & Deployment:** Git syntax, GitHub workflows, repository management, and live site deployment via Netlify.

### 🔹 Module 2: JavaScript Core
* **JavaScript Fundamentals:** Variables, data types, control flow, functions, and ES6+ features.
* **DOM Manipulation:** Selecting elements, modifying styles, creating/removing dynamic elements.
* **Event Handling:** Click, submit, change, scroll, and keyboard events.
* **Form Validations:** Client-side input validation and error handling.
* **APIs & Asynchronous JS:** JSON parsing, Promises, and fetching real-time data via `fetch()`.

### 🔹 Module 3: Core Backend & Database Development
* **PHP Fundamentals:** Syntax, data types, operators, functions, arrays, and control structures.
* **Form Processing:** Working with `$_POST` and `$_GET` superglobals for server-side processing.
* **MySQL Database:** Database design, relational tables, primary/foreign keys, phpMyAdmin management.
* **Core PHP CRUD Application:** Building a full-fledged functional application (e.g., Student Management System / Blog Engine) with full Create, Read, Update, Delete capabilities.

### 🔹 Module 4: WordPress & E-Commerce Mastery
* **Environment Setup:** Local development server setup using XAMPP or LocalWP.
* **WordPress Core:** Dashboard navigation, user management, posts, pages, and taxonomy.
* **Site Building:** Page builders (Elementor / Gutenberg), custom layouts, responsive design, and essential security/speed plugins.
* **E-Commerce:** Setting up full WooCommerce online stores, product catalogs, shipping rules, and payment gateways.
* **Advanced CMS Architecture:** Utilizing Core PHP knowledge to build basic custom WordPress themes, child themes, and custom code inside `functions.php`.

## 🎯 Course Outcomes & Objectives

By the end of this course, students will be able to:
1. Build pixel-perfect, mobile-first responsive websites using HTML, CSS, and Bootstrap.
2. Track code changes and publish live client websites using Git, GitHub, and Netlify.
3. Write clean JavaScript for interactive features and dynamic API data fetching.
4. Design relational MySQL databases and handle backend business logic using Core PHP.
5. Deliver client-ready, secure, and fast commercial WordPress & WooCommerce websites.
